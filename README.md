## Projects

### Guessing Game
Number guessing game using while loops, conditionals, and random module.

### Quiz Game
5-question multiple choice quiz with input validation and score tracking.
- Accepts only a/b/c/d inputs
- Shows full correct answer on wrong response
- Displays final score out of 5

### Rock Paper Scissors
Two implementations of the same game demonstrating different approaches.
- **Method 1** — if/elif logic
- **Method 2** — dictionary matrix lookup
- Built to compare readability and scalability of both solutions
