## Projects

### 🎮 Guessing Game
A number guessing game built using while loops, conditionals,
and Python's random module.
- Randomly generates a number between 1 and 100
- Gives higher/lower hints
- Tracks number of attempts

### ❓ Quiz Game
A 5-question multiple choice quiz with score tracking.
- Input validation — only accepts a/b/c/d
- Shows correct answer on wrong response
- Displays final score out of 5

### ✂️ Rock Paper Scissors
Two implementations of the same game demonstrating different
approaches to the same problem.
- **Method 1** — if/elif logic
- **Method 2** — dictionary matrix lookup
- Built to compare readability and scalability of both solutions
- Includes input validation
